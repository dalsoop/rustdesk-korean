# 우리 기기 접속 비밀번호 저장 (ranode)

What changed in ko.25
- **RustDesk (forked ranode) can keep the access password of each own device (decision 0010).** `RustDeskPublic --save-peer-password <Tailscale address>` (as the logged-in user, the password on stdin only) stores it encrypted with the Mac's key in ranode's own config folder. A click on that device's on-prem card (or any new session to that exact Tailscale address without a password) then connects without the password prompt; the value is hashed with the peer's salt as upstream does and never appears in the UI, logs or the command line. A wrong saved password ends in the usual "wrong password" prompt.
- The main app ("RustDesk (for korean)"), Windows, Linux and Android work as in ko.24; their files are rebuilt from the ko.25 commit with the new version numbers.
