# 맥에서 Caps Lock 한/영이 원격 맥에서 두 번 바뀌던 문제

What changed in ko.26
- **Caps Lock as the 한/영 key switches the remote Mac once.** On a controlling Mac with "Caps Lock 키로 ABC 입력 소스 전환" on, macOS reports one Caps Lock press as two key-downs a few milliseconds apart; up to ko.25 each became a 한/영 key for the peer, so the remote input source switched twice and looked unchanged. Caps Lock key-downs less than 80 ms apart now count as one press. Shortcuts (F18, ⌃Space, ⌃⌥Space) were not affected.
- Both macOS apps ("RustDesk (for korean)" and "RustDesk (forked ranode)") carry the fix on their controlling side. Windows, Linux and Android are rebuilt from the ko.26 commit with no change since ko.25.
